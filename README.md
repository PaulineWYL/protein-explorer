# Excel 檔案快速視覺化工具

一個輕量級的 Web UI，用於快速上傳、查看和分析 Excel 檔案。✨

## 功能特色

✅ **無需安裝** - 純前端解決方案，所有処理都在瀏覽器中進行  
✅ **快速上傳** - 支持拖曳上傳或點擊選擇檔案  
✅ **智能表格** - 可搜尋、分頁、可調整大小的互動式表格  
✅ **自動圖表** - 自動分析數據並生成圖表  
✅ **統計分析** - 顯示行數、欄數、數字欄位等基本統計  
✅ **多工作表** - 支持 Excel 多工作表切換  
✅ **隱私安全** - 檔案完全在本地處理，不上傳到任何伺服器

## 支持格式

- Excel 2007+ (`.xlsx`)
- Excel 97-2003 (`.xls`)
- CSV 檔案 (`.csv`)
- 檔案大小限制：50MB 以內

## 快速開始

### 方式 1: 雙擊啟動（推薦）

直接雙擊 `start_server.bat` 檔案，會自動打開瀏覽器。

### 方式 2: 命令行啟動

```bash
cd c:\Users\PaulineWang\Desktop\protein
python -m http.server 8000
```

然後在瀏覽器中打開 `http://localhost:8000`

### 方式 3: 直接打開

直接在瀏覽器中打開 `index.html` 檔案（拖曳 `index.html` 到瀏覽器）

## 使用方式

1. **上傳檔案**
   - 拖曳 Excel 檔案到上傳區域，或點擊「選擇檔案」按鈕

2. **查看數據**
   - 「表格檢視」標籤：查看完整數據表格
   - 「圖表分析」標籤：自動生成的統計圖表
   - 「檔案資訊」標籤：詳細的列資訊統計

3. **互動操作**
   - 搜尋：在表格標題下方輸入搜尋條件
   - 排序：點擊欄標題進行排序
   - 調整欄寬：拖曳欄邊界調整寬度
   - 複製：選擇儲存格並複製到剪貼板

## 技術棧

- **前端框架**: 純 JavaScript (無框架依賴)
- **表格庫**: Tabulator.js - 強大的數據表格
- **圖表庫**: Chart.js - 簡潔的圖表繪製
- **Excel 解析**: SheetJS (xlsx) - 廣泛支持的 Excel 庫
- **樣式**: 現代化的 CSS3 設計

## 常見問題

**Q: 檔案會被上傳到伺服器嗎？**  
A: 不會。所有數據處理都在您的瀏覽器中本地進行。

**Q: 支持大檔案嗎？**  
A: 支持到 50MB。對於超大檔案，可能需要更多的瀏覽器記憶體。

**Q: 可以離線使用嗎？**  
A: 可以，但需要網際網路連接下載 CDN 資源（表格、圖表庫等）。如需完全離線，可下載相關庫的本地版本。

**Q: 在什麼瀏覽器上工作？**  
A: 所有現代瀏覽器都支持（Chrome、Firefox、Safari、Edge）
